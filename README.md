## 👋 About Me

I'm **MD. Hasib Islam**, a Computer Science and Engineering graduate from Bangladesh with an interest in cybersecurity, penetration testing, responsible vulnerability research, and software development.

I enjoy exploring how applications and systems work, identifying security weaknesses in authorized environments, and building tools that make technical workflows more efficient.

- 🔐 **Cybersecurity:** Web application security, penetration testing, reconnaissance, and vulnerability assessment.
- 🧪 **Research:** Authentication systems, phishing detection, security automation, and malware behavior analysis.
- ⚙️ **Development:** Python utilities, scripting, and local-first assistant concepts.
- ☁️ **Learning:** Cloud security, defensive security, and secure software design.
- 🤝 **Collaboration:** Interested in responsible security research and practical development projects.

> I support ethical, authorized security testing conducted within a clearly defined scope.
